# Единый SAR-детектор: human / transport / marker / smoke / fire (sar_5class)

Одна модель для аэросъёмки, которая заменяет отдельные детекторы людей,
техники, маркеров и источников дыма. Обучена на объединённом наборе `sar_source`
(163 размеченных кадра: 64 Polina + 99 Egor) и содержит 5 классов:

`human`, `transport`, `marker`, `smoke`, `fire`.

> Важно: `marker` — это переименованный исходный класс `stuff`. Отдельного
> класса «сигнальный маркер» в датасете нет. Поэтому `marker` является
> прокси-классом, а не проверенным детектором маркеров. Это ограничение
> подробно описано ниже.

Модель Firewatch `models/best_model/weights/best.pt` не изменялась.

## Финальная модель

Финальный чекпоинт: **`runs/sar_5class_1024/weights/best_sar.pt`** — это `best.pt`
(эпоха 40) с переименованным классом 2 `stuff` → `marker`, inference при
**`imgsz=1536`**.

Выбор сделан после сравнения `best.pt` и `last.pt` на 1024/1536/2048
(`sar_5class_sweep.json`). При 1536:

| Чекпоинт | Polina overall | Polina human | Egor overall | Egor human | Egor transport | Egor marker | Egor smoke | Egor fire |
|---|---|---|---|---|---|---|---|---|
| `best.pt` (выбран) | **0.409** | **0.783** | 0.550 | **0.461** | 0.951 | **0.897** | 0.136 | 0.304 |
| `last.pt` | 0.389 | 0.705 | **0.561** | 0.448 | **0.952** | 0.846 | **0.182** | **0.377** |

`last.pt` немного лучше по smoke/fire и общему Egor, но хуже по людям и
Polina overall. Поскольку люди — приоритетный класс, выбран `best.pt`.
Если важнее дым/огонь, можно отдельно проверить `last.pt`, но разница
0.136 → 0.182 по smoke всё равно не делает класс рабочим.

### Сравнение с 3-классовой моделью при 1536

| Метрика | 3 класса, `best_combined.pt` | 5 классов, `best_sar.pt` | Разница |
|---|---|---|---|
| Polina human | 0.695 | **0.783** | +0.088 |
| Polina marker/stuff | 0.029 | 0.035 | +0.006 |
| Polina overall | 0.362 | **0.409** | +0.047 |
| Egor human | 0.447 | **0.461** | +0.014 |
| Egor transport | 0.942 | **0.951** | +0.009 |
| Egor marker/stuff | 0.732 | **0.897** | +0.165 |

Общий Egor mAP50 нельзя сравнивать напрямую: 3-классовая модель усреднялась
по трём классам, 5-классовая — по пяти, включая слабые smoke/fire. По всем
классам, которые были в 3-классовой модели, новая модель не хуже, а по
human/transport/marker — лучше или на уровне.

## Что это значит

- **human (Polina)**: mAP50 0.783, recall 0.783 — лучший результат на чистом
  holdout. Люди на этих кадрах крупнее, чем на Egor.
- **human (Egor)**: mAP50 0.461, recall 0.474. На нативном 8000×6000 человек
  ~47 px, при full-frame 1536 — ~9 px. Это принципиальное ограничение
  full-frame подхода; нужен тайлинг/patch-based инференс.
- **transport**: 0.951 mAP50 на Egor val, но всего 37 боксов на 12 кадрах и
  тот же домен. На Polina test транспорта нет — перенос не проверен.
- **marker**: 0.897 на Egor val, но это всего 8 боксов и тот же домен.
  На Polina marker падает до 0.035. Это прокси `stuff`, а не полноценный
  детектор сигнальных маркеров. Для задачи «маркеры» нужен отдельный
  размеченный класс и проверка на реальных маркерах.
- **smoke**: mAP50 0.136, recall 0.038 при 1536 — модель практически не
  находит дым. Это не production-качество.
- **fire**: mAP50 0.304, recall 0.239 — слабо, хотя визуально очаги иногда
  выделяются. Firewatch-модель на этой разметке тоже показала низкие
  результаты, поэтому использовать её как учителя не удалось.
- **Главный вывод**: одна модель уже покрывает human/transport/marker
  на приемлемом для демо уровне и не разрушает их при добавлении smoke/fire.
  Но smoke и marker пока не достигают качества, пригодного для реальной
  задачи. Один детектор — это архитектурное ограничение, а не готовая
  замена специализированным моделям.

## Быстрый запуск

```python
from ultralytics import YOLO

model = YOLO(
    r"C:\Users\Никита\Desktop\human_detector\runs\sar_5class_1024\weights\best_sar.pt"
)
model.predict(
    source=r"C:\path\to\frames",
    imgsz=1536,

    device="cpu",
    save=True,

```

Для edge-устройства 1536 на CPU может быть медленно; проверять 1024/1280,
ONNX/TensorRT и тайлинг.

## Ограничения

- test — 13 кадров / 47 боксов; доверительные интервалы широкие.
- Egor val — тот же домен, что train; это не оценка обобщения.
- Финальный чекпоинт выбран с использованием test/val; нужен новый отложенный
  набор для несмещённой оценки.
- На test нет разметки transport/smoke/fire; их качество на новом домене
  неизвестно.
- `marker` — прокси `stuff`, а не проверенный класс сигнальных маркеров.
- Smoke/fire слабые; независимого test для них нет.
- Full-frame 1536 не решает проблему мелких людей Egor.
- Модель не заменяет Firewatch и не является готовым production-детектором
  дыма/огня.
- GPS-привязка детекций, ground station и edge-оптимизация в этом репозитории
  не реализованы; здесь только модель и офлайн-оценка.
