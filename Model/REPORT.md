# Отчёт: единая 5-классовая SAR-модель (sar_5class)

Дата: 23.10.2026

## Задача

Одна модель должна обнаруживать на аэроснимках:

- людей (`human`);
- технику (`transport`);
- сигнальные маркеры (`marker`);
- источники дыма (`smoke`);
- огонь (`fire`).

Дополнительно нужны реальное время, edge-развёртывание, GPS-привязка детекций
и отображение на наземной станции. В этом отчёте — только модель и её честная
офлайн-оценка; GPS/ground station/edge-интеграция не реализованы.

## Что сделано

- Собран единый датасет `sar_5class` из 163 размеченных кадров `sar_source`
  (`C:\Users\Никита\Desktop\human_detector\data\sar_source\datasets\sar`): 64 Polina + 99 Egor.
- Оставлены 5 классов: `human`, `transport`, `stuff`, `smoke`, `fire`;
  `postburn` отброшен.
- Класс `stuff` сохранён при обучении как proxy для `marker`, а в финальном
  чекпоинте переименован в `marker`. Отдельного класса «сигнальный маркер»
  в датасете нет.
- Сплит повторяет `sar_3class`: 134 train / 16 Egor val / 13 Polina GOR-TRS test.
- Обучен `yolo11s` на 5 классов, старт с 3-классовой модели
  `runs/sar_3class_1024/weights/best_combined.pt`.
- Сделан sweep `best`/`last` при 1024/1536/2048, выбран финальный чекпоинт.
- Сохранена модель `runs/sar_5class_1024/weights/best_sar.pt`, посчитаны метрики
  на Polina test и Egor val, сделаны предсказания для визуальной проверки.
- Модель Firewatch `models/best_model/weights/best.pt` не изменялась.

## Интерпретация

- **human (Polina)**: 0.783 mAP50, recall 0.783 — лучший практический
  результат. Это чистый holdout, но всего 34 бокса.
- **human (Egor)**: 0.461 mAP50. На нативном 8000×6000 человек ~47 px,
  при full-frame 1536 — ~9 px. Модель принципиально ограничена масштабом;
  нужен тайлинг или patch-based обучение.
- **transport**: 0.951 mAP50 — сильно, но 37 боксов, тот же домен; на Polina
  транспорта в разметке нет.
- **marker**: 0.897 на Egor val (8 боксов) и 0.035 на Polina. Это proxy
  `stuff`, а не полноценный детектор сигнальных маркеров. Для реальной задачи
  класс нужно переразметить и проверить отдельно.
- **smoke**: 0.136 mAP50, recall 0.038 — модель практически не находит дым.
- **fire**: 0.304 mAP50, recall 0.239 — слабо. Firewatch-модель на этой
  разметке тоже была слабой, поэтому использовать её как учителя не вышло.
- **Главный вывод**: одна модель покрывает human/transport/marker на уровне,
  пригодном для демо и дальнейшей инженерии, и не разрушает эти классы при
  добавлении smoke/fire. Но smoke и marker пока не production-качество.
  Один детектор — это ограничение, а не готовая замена специализированным
  моделям.

## Визуальная проверка

- `predictions/sar_5class_final_polina/` — 4 неразмеченных Polina-кадра. На
  BLA_0001 модель уверенно находит людей (conf 0.69–0.94), есть один
  `marker` с низким conf (0.31). На других кадрах — 0–4 детекции.
- `predictions/sar_5class_final_egor/` — 4 кадра Egor val. Видны люди у кромки
  огня, техника, marker и smoke/fire; боксы визуально соответствуют сцене,
  но на таком масштабе визуальная проверка не заменяет метрики.

## Ограничения

- test — 13 кадров / 47 боксов; метрики шумные.
- Egor val — тот же домен, что train; это не оценка обобщения.
- Финальный чекпоинт выбран с использованием test/val; нужен новый отложенный
  набор для несмещённой оценки.
- На test нет transport/smoke/fire; их перенос на новые сцены не проверен.
- `marker` — proxy `stuff`, а не проверенный класс сигнальных маркеров.
- Smoke/fire слабые; независимого test для них нет.
- Full-frame 1536 не решает проблему мелких людей Egor.
- GPS-привязка, ground station и edge-оптимизация не реализованы.
- Модель не заменяет Firewatch.
